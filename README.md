## About CanvasDraft Studio

CanvasDraft Studio puts a full drawing workspace inside the browser. The rendering layer is a custom HTML5 canvas engine written in vanilla JavaScript, so the whole tool stays centered on drawing and editing instead of depending on a separate desktop program.

Its scene-based approach suits anyone who wants to build up canvas artwork and keep revisions tidy. Because undo and redo history is part of the editor itself, it is easy to experiment with a change and then step back to an earlier state without losing your place.

## FAQ

### Where does CanvasDraft Studio run?

### How do I get the newest build?

### Are undo and redo available?

Yes. Undo and redo history is integrated directly into the editing workflow.

### What does scene-oriented editing mean?

It is the model CanvasDraft Studio uses to treat drawing content as editable scenes that can be organized and revised.

### Do I have to install a desktop app?

No desktop installer is provided. CanvasDraft Studio is built as a browser-based application.

### The app will not start. What should I check?

Make sure JavaScript is enabled, verify that your browser supports HTML5 canvas, and confirm that locally served files are actually being delivered by a working web server.

The available project details do not point to a separate settings file or a persistent configuration location. Adjust whatever controls the current build exposes in the application interface.
